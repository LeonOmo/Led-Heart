# Led-Heart

A heart shaped PCB with 10 Leds which run in a loop. Build with an NE555 and a 4017.

## What is this project?



## Why does it exist?

- Christmas: Its a present made for christmas, i want to gift it to my sister.
- Dependence on Microcontrollers: I almost always just use microcontrollers so i made something without it.

## Features

- No Code needed
- Heart Shaped PCB
- Pixelart on PCB
- Adjustable loop Speed
