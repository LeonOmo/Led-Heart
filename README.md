# Led-Heart

A heart shaped PCB with 10 Leds which run in a loop. Build with an NE555 and a 4017.

## Why does it exist?

- Christmas: Its a present made for christmas, hence christmas is approching i wanted to make some gifts.
- Dependence on Microcontrollers: I almost always just use microcontrollers so i made something without one.

## Features

- No Code needed
- Heart Shaped PCB
- Adjustable loop Speed

## Components

| Reference | Component |
| :--- | :--- |
| U1 | 4017 |
| U2 | NE555P |
| D1 to D10 | LEDs |
| R1 | 470 resistor |
| R2 | 1k resistor |
| RV1 | 50k potentiometer (speed) |
| C1 | 1 µF capacitor |
| C2 | 0.01 µF capacitor |
| J1, J2 | Power pads (5 V and GND) |
| PCB | Custom heart PCB |
